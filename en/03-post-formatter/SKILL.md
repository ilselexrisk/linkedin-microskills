# LinkedIn Post Formatter

## Why this skill exists
Most LinkedIn reading happens on a phone, mid-scroll. Good ideas lose readers when they arrive as dense paragraphs. Jasmin Alić calls rhythm and structure a core part of the craft: vary line length, use repetition on purpose and break the pattern.

## Inputs
- **Draft:** any length or state.
- **Hook:** chosen hook (optional; if missing, keep the draft's first line).
- **CTA goal:** comment / DM / visit link in comments / download / follow.

## Formatting rules
1. **Hook block:** 1–2 lines, then a blank line. Nothing else may sit above the "…see more" fold.
2. **Rehook:** line 2 or 3 gives the reader a reason to keep going (stakes, tension or "here's how").
3. **Short paragraphs:** 1–3 lines each, with a blank line between.
4. **Vary rhythm:** mix one-word lines, short sentences and the occasional longer sentence. Don't make every line a single sentence ("broetry"). That reads as spam, especially in Nordic markets.
5. **Lists:** use "→" or numbers for steps. At most 7 items.
6. **One idea:** cut anything that doesn't serve the core takeaway.
7. **Length:** aim for 120–250 words for text posts. Go longer only if every line earns its place.
8. **Links:** never in the post body, because external links reduce reach. Put them in the first comment and say "link in comments".
9. **Hashtags:** 0–3, at the end, only if they're specific.
10. **CTA:** exactly one, at the end, matched to the goal (see below).

## CTA menu (choose one)
| Goal | Soft (default) | Direct |
|---|---|---|
| Comments | Ask a specific question about their situation | "Agree or disagree?" |
| Leads | "I made a [free resource] for this; link in comments" | "DM me '[word]' and I'll send it" |
| Calls | "If this is you, my DMs are open" | "Book 15 min, link in comments" |

Default to **soft**. Gated "comment X to get it" CTAs work for reach, but some top creators (e.g. Adam Robinson) advise against them because they can feel gimmicky. Use them only if the user asks.

## Process
1. Find the core takeaway. If the draft has two, flag it and suggest splitting it into two posts.
2. Apply the rules above.
3. Read it as a sceptical buyer would and cut any sentence they'd skim.
4. Output the final post, then a short checklist.

## Output format
```
[FINAL POST — copy-paste ready]

---
CHECKLIST
✓/✗ Hook fits above the fold
✓/✗ Rehook in lines 2–3
✓/✗ One idea only
✓/✗ No links in body
✓/✗ One CTA, matches goal
Word count: N
First comment (if a link is needed): …
```
